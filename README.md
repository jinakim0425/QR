# QR 기반 공용기자재 예약·반납 시스템

> 스터디카페 공용 물품의 실시간 잔여 수량 조회와 QR 코드 기반 대여·반납을 지원하는 웹 서비스

ICT특성화취업연계형사업단 13기 개인 풀스택 프로젝트 (2026년 2학기)

<br>

## 프로젝트 개요

스터디카페에서 독서대, 담요, 충전기, 보조배터리 등 공용 물품을 이용할 때
남은 수량을 알 수 없어 카운터까지 직접 확인하러 가야 하고,
반납 관리가 이루어지지 않아 분실·부족 현상이 반복되는 문제가 있습니다.

본 서비스는 물품별 잔여 수량을 앱에서 실시간으로 확인하고,
현장에 부착된 QR 코드를 스캔해 즉시 대여·반납할 수 있도록 하여
이용자의 불편과 관리자의 재고 관리 부담을 동시에 줄이는 것을 목표로 합니다.

<br>

## 주요 기능

| 구분 | 기능 |
| --- | --- |
| 조회 | 물품별 실시간 잔여 수량 조회, 상세 정보 확인 |
| 대여 | 현장 QR 스캔을 통한 즉시 대여 처리 |
| 반납 | 반납 QR 스캔 시 재고 자동 반영 |
| 예약 | 사전 예약 및 예약 취소, 예약 만료 처리 |
| 이력 | 개인 대여·반납 이력 조회 |
| 관리자 | 물품 등록·수정, 재고 현황 및 연체 관리 |

<br>

## 이용자 흐름

1. 서비스 접속 후 메인 화면에서 공용기자재 실시간 잔여 수량 확인
2. 원하는 물품 선택 후 현장 QR 코드 스캔 → 대여 처리
3. 대여 상태 및 반납 예정 시각 확인
4. 사용 종료 후 반납 QR 스캔 → 재고 자동 반영 및 이력 저장

## 실행 방법

```bash
# 저장소 클론
git clone https://github.com/jinakim0425/QR.git
cd QR

# 백엔드 실행
cd backend
./gradlew bootRun

# 프론트엔드 실행
cd ../frontend
npm install
npm run dev
```
