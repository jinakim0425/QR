# 서비스 흐름 정의서

**프로젝트명** QR 기반 공용기자재 예약·반납 시스템

**작성자** 김진아

**작성일** 2026-09-08

**버전** v1.0

<br>

## 1. 문서 목적

이용자와 관리자가 서비스를 사용하는 과정을 단계별로 정의하고,
각 단계에서 발생하는 상태 변화와 예외 상황을 정리하여
기능 요구사항의 누락 여부를 검증하는 것을 목적으로 한다.

<br>

## 2. 이용자 흐름

### 2.1 기본 흐름 (조회 → 대여 → 반납)

```
[서비스 접속]
      │
      ▼
[메인 화면 - 물품별 실시간 잔여 수량 확인]
      │
      ▼
[원하는 물품 선택]
      │
      ▼
[현장 QR 코드 스캔]
      │
      ▼
[대여 처리 - 재고 차감, 반납 예정 시각 안내]
      │
      ▼
[물품 사용]
      │
      ▼
[반납 장소 QR 코드 스캔]
      │
      ▼
[반납 처리 - 재고 복구, 이력 저장]
```

| 단계 | 이용자 행위 | 시스템 처리 | 관련 기능 |
| --- | --- | --- | --- |
| 1 | 서비스 접속 및 로그인 | 계정 인증, 메인 화면 진입 | FR-02 |
| 2 | 물품 목록 확인 | 물품별 실시간 잔여 수량 조회 및 표시 | FR-04 |
| 3 | 물품 선택 | 물품 상세 정보 및 반납 장소 안내 | FR-05 |
| 4 | 현장 QR 코드 스캔 | QR 값으로 물품 식별, 대여 가능 여부 검증 | FR-06, FR-08 |
| 5 | 대여 확정 | 대여 건 생성, 재고 차감, 반납 기한 계산 | FR-07, FR-09 |
| 6 | 물품 사용 | 대여 중 상태 유지 | — |
| 7 | 반납 장소 QR 스캔 | 해당 대여 건 조회 및 반납 처리 | FR-10 |
| 8 | 반납 완료 확인 | 재고 복구, 반납 시각 기록, 이력 저장 | FR-11, FR-12 |

### 2.2 예약 흐름

| 단계 | 이용자 행위 | 시스템 처리 | 관련 기능 |
| --- | --- | --- | --- |
| 1 | 물품 예약 요청 | 재고 선점, 예약 만료 시각 설정 | FR-13 |

| 2-b | 예약 취소 | 선점 재고 즉시 복구, 예약 상태 취소로 변경 | FR-14 |

## 4. 상태 정의

### 4.1 대여 상태

```
[대여중] ──반납 QR 스캔──▶ [반납완료]
    │
    └──반납 기한 초과──▶ [연체] ──반납 QR 스캔──▶ [반납완료]
```

| 상태 | 설명 |
| --- | --- |
| 대여중 | 물품을 수령하여 사용 중이며 아직 반납되지 않은 상태 |
| 연체 | 반납 기한을 초과했으나 반납되지 않은 상태 |
| 반납완료 | 반납 처리가 완료되어 재고가 복구된 상태 |

### 4.2 예약 상태

```
[예약중] ──QR 스캔 수령──▶ [수령완료] ──▶ 대여 상태로 전환
    │
    ├──이용자 취소──▶ [취소]
    │
    └──만료 시각 도달──▶ [만료]
```

| 상태 | 설명 | 재고 반영 |
| --- | --- | --- |
| 예약중 | 물품이 선점되어 다른 이용자가 대여할 수 없는 상태 | 잔여 수량에서 제외 |
| 수령완료 | 예약자가 QR을 스캔하여 대여로 전환된 상태 | 대여 중 수량으로 이동 |
| 취소 | 이용자가 직접 예약을 취소한 상태 | 잔여 수량 복구 |
| 만료 | 만료 시각까지 수령하지 않아 자동 해제된 상태 | 잔여 수량 복구 |

## 5. 예외 흐름

| 상황 | 처리 방식 | 관련 기능 |
| --- | --- | --- |
| 잔여 수량이 0인 물품을 대여 시도 | 대여를 차단하고 품절 안내 메시지를 표시한다 | FR-08 |
| 미반납 건이 있는 이용자가 추가 대여 시도 | 대여를 차단하고 기존 미반납 건을 안내한다 | FR-08 |
| 등록되지 않은 QR 코드를 스캔 | 물품 식별 실패 메시지를 표시하고 처리를 중단한다 | FR-06 |
| 대여 이력이 없는 상태에서 반납 QR 스캔 | 대응되는 대여 건이 없음을 안내한다 | FR-10 |
| 만료된 예약으로 현장 QR 스캔 | 예약이 만료되었음을 안내하고 잔여 수량 기준으로 재대여를 유도한다 | FR-15, FR-16 |
| 동시에 마지막 1개 물품에 대여 요청 발생 | 재고 검증과 차감을 하나의 트랜잭션으로 처리하여 중복 대여를 방지한다 | 비기능 요구사항 |

## 6. 흐름 검증 결과

이용자·관리자 흐름을 단계별로 대조한 결과 다음 항목이 요구사항에서 누락되어 추가하였다.

| 발견 항목 | 조치 |
| --- | --- |
| 예약 만료 시 재고가 복구되지 않고 계속 선점되는 문제 | FR-15 예약 자동 만료 기능 추가 |
| 관리자가 반납 기한 초과 건을 확인할 방법 부재 | FR-21 미반납·연체 목록 조회 기능 추가 |
| 예약 상태에서 현장 수령 시 대여로 전환하는 절차 미정의 | FR-16 예약 수령 처리 기능 추가 |
