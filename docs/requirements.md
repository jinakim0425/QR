# 기능 요구사항 정의서

**프로젝트명** QR 기반 공용기자재 예약·반납 시스템

**작성자** 김진아

**작성일** 2026-09-08

**버전** v1.0

<br>

## 1. 문서 목적

본 문서는 QR 기반 공용기자재 예약·반납 시스템에서 제공해야 할 기능을 정의하고,
각 기능의 우선순위와 제약 조건을 명확히 하여 이후 설계 및 구현의 기준을 마련하는 것을 목적으로 한다.

<br>

## 2. 용어 정의

| 용어 | 설명 |
| --- | --- |
| 공용기자재 | 스터디카페에서 이용자가 공용으로 사용하는 물품 (독서대, 담요, 충전기, 보조배터리 등) |
| 대여 | 이용자가 물품을 수령하여 사용 중인 상태 |
| 반납 | 대여한 물품을 지정 장소에 되돌려 놓고 대여 건을 종료하는 행위 |
| 예약 | 물품을 수령하기 전에 미리 선점해 두는 행위 |
| 잔여 수량 | 총 보유 수량에서 대여 중 수량과 예약 선점 수량을 제외한 수량 |
| 연체 | 반납 기한을 초과했으나 반납되지 않은 상태 |

<br>

## 3. 사용자 정의

| 구분 | 설명 | 주요 활동 |
| --- | --- | --- |
| 이용자 | 스터디카페를 이용하며 공용기자재를 사용하는 일반 사용자 | 잔여 수량 조회, 예약, QR 대여·반납, 이력 확인 |
| 관리자 | 스터디카페 운영자 | 물품 등록·수정, QR 코드 발급, 재고 현황 점검, 미반납 관리 |

<br>

## 4. 기능 요구사항 목록

우선순위 — **상**: 핵심 기능(필수 구현), **중**: 주요 기능, **하**: 여유 시 구현

### 4.1 회원

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-01 | 회원가입 | 이름, 연락처, 비밀번호를 입력받아 계정을 생성한다 | 중 |
| FR-02 | 로그인 / 로그아웃 | 등록된 계정으로 인증하고 세션을 종료한다 | 상 |
| FR-03 | 내 정보 조회 | 현재 대여 중인 물품과 반납 예정 시각을 확인한다 | 중 |

### 4.2 조회

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-04 | 물품 목록 조회 | 전체 공용기자재 목록과 물품별 실시간 잔여 수량을 표시한다 | 상 |
| FR-05 | 물품 상세 조회 | 물품 설명, 총 보유 수량, 대여 중 수량, 반납 장소를 표시한다 | 중 |

### 4.3 대여

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-06 | QR 스캔 대여 | 현장 QR 코드를 스캔하여 물품을 식별하고 대여 건을 생성한다 | 상 |
| FR-07 | 재고 자동 차감 | 대여 확정 시 해당 물품의 잔여 수량을 즉시 감소시킨다 | 상 |
| FR-08 | 대여 가능 여부 검증 | 잔여 수량 부족, 미반납 건 보유, 대여 한도 초과 시 대여를 차단한다 | 상 |
| FR-09 | 반납 기한 안내 | 대여 시 반납 예정 시각을 계산하여 이용자에게 표시한다 | 중 |

### 4.4 반납

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-10 | QR 스캔 반납 | 반납 장소의 QR 코드를 스캔하여 해당 대여 건을 종료 처리한다 | 상 |
| FR-11 | 재고 자동 복구 | 반납 완료 시 해당 물품의 잔여 수량을 즉시 증가시킨다 | 상 |
| FR-12 | 반납 결과 확인 | 반납 완료 여부와 처리 시각을 이용자에게 표시한다 | 중 |

### 4.5 예약

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| FR-13 | 물품 예약 | 원하는 물품을 미리 선점하고 예약 만료 시각을 설정한다 | 중 |
| FR-14 | 예약 취소 | 이용자가 예약을 취소하면 선점된 재고를 즉시 복구한다 | 중 |
| FR-15 | 예약 자동 만료 | 만료 시각까지 수령하지 않은 예약을 자동 해제하고 재고를 복구한다 | 중 |
| FR-16 | 예약 수령 처리 | 예약 상태에서 QR 스캔 시 예약을 대여로 전환한다 | 중 |

### 4.7 관리자

| FR-19 | QR 코드 발급 | 물품별 고유 QR 코드를 생성하고 출력용으로 제공한다 | 상 |
| FR-20 | 재고 현황 조회 | 물품별 총 수량, 대여 중, 예약 중, 잔여 수량을 한눈에 확인한다 | 상 |

| FR-22 | 재고 수동 보정 | 분실·파손 등으로 실물 수량이 달라진 경우 수량을 조정한다 | 하 |

## 5. 비기능 요구사항

| 구분 | 내용 |
| --- | --- |
| 성능 | 물품 목록 및 잔여 수량 조회 응답 시간 2초 이내 |
| 정합성 | 동시 대여 요청이 발생해도 잔여 수량이 음수가 되지 않도록 처리 |
| 보안 | 관리자 전용 기능은 권한 검증을 거친 사용자만 접근 가능 |
| 사용성 | 현장에서 QR 스캔이 이루어지므로 모바일 화면을 우선 고려 |
| 확장성 | 물품 종류 추가 시 코드 수정 없이 데이터 등록만으로 반영 가능 |

<br>

## 6. 제약 사항

- 개인 프로젝트로 진행하며 개발 기간은 12주(2026년 8월 24일 ~ 11월 15일)이다.
- QR 스캔은 모바일 웹 브라우저의 카메라 기능을 활용한다.
- 실제 스터디카페 운영 시스템과의 연동은 범위에서 제외하며, 자체 데이터로 시뮬레이션한다.
- 결제 및 보증금 관련 기능은 범위에서 제외한다.
